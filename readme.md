# 🍋 Virtual Lemon Tree Room (Vue 3 + Three.js + GSAP)

Інтерактивна **віртуальна кімната з лимонним деревом**, створена на Vue 3 з використанням Three.js та GSAP ScrollTrigger.
Під час прокрутки користувач “заходить” у кімнату і проходить по колу навколо дерева.
Дерево процедурно згенероване: стовбур, гілки, листя й лимони створюються на льоту без 3D-моделей.

---

## 🧰 Технології

- **Vue 3 (Composition API)** — основа застосунку
- **Vite** — збірка та dev-сервер
- **Three.js** — тривимірна графіка (сцена, камера, матеріали, світло)
- **GSAP 3 + ScrollTrigger** — керування камерою під час скролу, плавна анімація
- **InstancedMesh** — продуктивне рендерення тисяч листків і лимонів
- **Fog, Shadows, ACES tone mapping** — кінематографічне освітлення
